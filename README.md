# Fieldnotes

A four-page static website about organizing work and reflecting on progress. All examples are fictional. No personal data is collected or stored.

Open index.html locally or serve this folder with a static server. No build or dependencies are required.

For GitHub Pages, upload index.html, workspace.html, review.html, about.html, style.css, script.js, and .nojekyll to your repository. Enable Pages for the repository branch and root folder.
